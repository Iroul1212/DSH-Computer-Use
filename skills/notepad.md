---
app: 记事本
match: notepad.exe, Notepad, 记事本
summary: 纯文本输入、查找替换、编码与另存为
---
- 输入即插入；ctrl+a 全选、ctrl+c/v/x 复制粘贴剪切、ctrl+z 撤销。
- 查找 ctrl+f、替换 ctrl+h；查找下一个 F3。
- 另存为 ctrl+shift+s（或「文件 → 另存为」）：注意底部「编码」下拉要选 UTF-8，否则中文可能乱码。
- 自动换行：「格式 → 自动换行」；状态栏可看行列号。
- 时间戳插入 F5（部分版本）。
- Windows 11 记事本支持多标签：ctrl+t 新建标签、ctrl+w 关闭标签、ctrl+Tab 切换。
- 大文件用记事本打开会卡，改用 VS Code 或其他编辑器。
